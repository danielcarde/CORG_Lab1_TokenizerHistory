# Lab1: C Tokenizer and History

A C systems programming lab that implements tokenization and command-history components.

## Highlights
Separates tokenizer and history code into modules.
Includes matching .c and .h files.
Builds with the included makefile.
Practices lower-level string and memory handling.

## Overview
This lab implements a small C program with separate tokenizer and history modules. The tokenizer breaks input into pieces, while the history component stores previous entries.
The project is organized like a small systems assignment with headers, implementation files, and a makefile.

## Why This Project
This project demonstrates lower-level programming skills that are different from the Java labs. It shows C compilation, modular source organization, and command-line program structure.

## Usage
Compile: Run make from the lab folder in an environment with a C compiler and make.
Run: Execute the compiled program generated by the makefile.
If using Windows, use WSL, MSYS2, or another shell that supports make and GCC or Clang.

## Installation
Install GCC or Clang and make.
On Windows, WSL or MSYS2 is recommended for the simplest build experience.

## Architecture
File Structure: The project contains main.c, tokenizer.c, tokenizer.h, history.c, history.h, and makefile.
Components: main.c drives the program, tokenizer.c handles token parsing, and history.c manages stored command history.
